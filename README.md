### Система интеграции с внешним сервисом для получения меню и отправки заказов. 
Решение включает 3 клиентские библиотеки, консольное приложение для обработки заказов и тестовый сервер-эмулятор для интеграционного тестирования работы сервиса.
В процессе работы приложение пишет логи в папку logs в корне приложения. Также можно настроить логгирование в консоль.
В файле "appsettings.json" можно менять параметры работы приложения, например порты или способ взаимодействия с сервисом (HTTP/GRPC).

## Для запуска окружения необходим Docker. 
В корневой папке проекта нужно запустить команду
```bash
docker-compose up --build
```
Это поднимет базу данных сервиса и запустит сервер-эмулятор для интеграционного тестирования.

## Схема работы консольного приложения:

1. Инициализация БД (создаётся автоматически через EnsureCreatedAsync())
2. Получение меню с сервера и сохранение в базу данных в таблицу MenuItems
3. Вывод меню в формате Название – Код – Цена
4. Ввод заказа одной строкой: Код1:Количество1;Код2:Количество2;...
5. Валидация ввода: проверка существования кодов и наличия блюд
6. Отправка заказа и вывод результата
